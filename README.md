# 🏃 逃げ切れ！

追いかけてくる青い球から、**60秒間逃げ切ることを目指す3Dゲーム**です。

障害物を利用しながら、制限時間が0になるまで逃げ続けます。

## 🎯 ゲームの目的

プレイヤーを追いかけてくる**青い球から60秒間逃げ切る**ことが目的です。

フィールドには多数の障害物が配置されており、それらを利用しながら青い球から逃げます。

制限時間が0になるまで捕まらずに逃げ切るとクリアです。
